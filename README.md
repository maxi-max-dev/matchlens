# MatchLens

Interactive football companion prototype with synthetic event replay, evidence-backed explanations, casual/analyst modes, and a five-minute recap.

Open index.html directly or serve this directory with a static HTTP server. No build step or API keys required.

All teams and match events are fictional. Explanations use deterministic rules, not an LLM. This version does not connect to live football feeds or Microsoft cloud services. Event locations are illustrative, not continuous player tracking. Detection thresholds are not validated on real matches.
